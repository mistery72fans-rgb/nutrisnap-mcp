# NutriSnap MCP Server (24/7 Cloud Bridge)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/mistery72fans-rgb/nutrisnap-mcp)

Model Context Protocol (MCP) server that connects the **NutriSnap** Android App with **ChatGPT** and **Claude**.

## Features
- **24/7 Cloud Available**: Runs independently of your PC.
- **Bearer Token Security**: Protected by `SECRET_KEY`.
- **Keep-Alive Endpoint**: `/api/health` for 24/7 uptime monitors.
- **ChatGPT & Claude MCP Tools**:
  - `get_daily_nutrition_summary`
  - `get_meal_history`
  - `log_food_item`
  - `get_diet_analysis_and_advice`
